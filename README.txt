# FocusClock PWA

This folder is a PWA-ready version of FocusClock V3.

Files:
- index.html — app
- manifest.json — install/app metadata
- sw.js — offline cache service worker
- icons/ — 192px and 512px app icons

Important:
A PWA must be served from HTTPS (or localhost for development). Opening index.html directly as a file will not provide normal PWA installation/service-worker behavior.

For free hosting, upload this folder to a static HTTPS host such as GitHub Pages.
